# dsh-tts — 语音朗读

把回复念出来。输入框下面一个小喇叭：亮着 = 自动朗读，熄灭 = 不读。

## 三种引擎

| 引擎 | 特点 | 需要什么 |
|---|---|---|
| 系统语音 | 本地合成、离线、免费、延迟最低 | 手机装了系统 TTS 引擎（大多数机器自带） |
| 云端 TTS | 音色多、语气自然 | OpenAI 兼容的 `/audio/speech` 接口 + API Key |
| 自定义 | 想用 RVC / GPT-SoVITS 之类自己的声音 | 一个"给文字、回音频"的 HTTP 接口 |

## 用法

1. 设置 →「语音朗读」→ 选引擎、调语速
2. 点输入框下面的小喇叭打开自动朗读（或者直接在设置里开关）
3. 朗读中再点一下喇叭 = 停止

## 实现要点

- **声音在原生**：安卓 WebView 没有 `speechSynthesis`，云端接口又有 CORS 限制，
  所以 `DshAndroid.ttsSpeak`（系统语音）/ `DshAndroid.ttsPlay`（云端/自定义）都由 `Tts.java` 实现。
- **读哪一段**：靠 DSH 消息节点上的 `data-chat-group-part="response"`、
  `data-chat-flow-key`、`data-chat-turn` 定位，并且**只有真的见过它流式生成**才念 ——
  翻旧会话、切工作区都不会突然出声。
- **念什么**：跳过代码块、工具调用卡片、按钮与图标；超长回复只念前 6000 字。
